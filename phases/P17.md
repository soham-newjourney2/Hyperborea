# P17 — Chennai (Velachery, TN) + Pune (Kharadi, MH)
**Depends on:** P16 · **Refs:** D-22

## Goal
Two Indian pilots with the full Sector V stack: OSM buildings/roads/facilities, Copernicus DEM, simulated drainage + power, weather/ERA5, CAMS→NAQI, WorldCover/NDVI/NDWI, access graph, surrogate, snapshots.

## Steps
1. Register sources in `docs/DATA_SOURCES.md` first: OSM (Overpass for the small bbox, Geofabrik India `southern-zone` / `western-zone` pbf fallback, ODbL); OpenCity GCC relief centres (Chennai, public domain) as curated facilities if usable; OpenCity PMC drain-channel data (Pune) as curated reference if machine-readable — otherwise documented as unusable (PDF).
2. Per region: boundary → fetch_osm → normalize_osm → fetch_dem → build_drainage (design storm per region) → make_sites → build_power → landcover → cv_water → build_access → climate → train_surrogate (per-region model) → snapshots.
3. Flood story checks: Chennai Velachery = low-lying lake basin (Dec 2015 / Dec 2023 Michaung); Pune Kharadi = Mula-Mutha riverside IT corridor. Presets shared; ERA5 record per region.
4. Audit passes per region (`audit_data.py --region`).

## Acceptance
Switch to each region → map, layers, Disaster heavy/extreme, Develop S1–S3, Access, Env all work; numbers recorded in LOG; audit PASS.
