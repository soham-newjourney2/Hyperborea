# P10 — Electrical network + cascade link
**Day:** Tue 10 Nov · **Depends on:** P08, P09 · **Refs:** D-09, planning §6–7, DATA_SOURCES `syn_power`

## Goal
A clearly **simulated** distribution network that extends the cascade (flooded transformer → buildings/facilities lose power) and activates the electrical check in development assessment.

## Steps
1. `pipelines/build_power.py`:
   - Use OSM `osm_power` features (substations/transformers) where present → `curated` (position from OSM; ratings unknown → assumed).
   - Synthetic transformers: k-means on building centroids (~1 per 40–60 buildings, tune to load), snapped to nearest road; rating from {100, 160, 250, 400, 630} kVA ≥ 1.25 × cluster peak; `plinth_m=0.6` (assumed).
   - Building peak load = BUA × W/m² (norms) × diversity 0.6 → `load_kva`; transformer `loading_pct`.
   - One 33/11 kV substation (OSM if present, else synthetic at a central site) → feeders.
   - Edges: `SUPPLIES` substation→transformer→building/facility; facility `DEPENDS_ON` transformer. All `simulated` unless OSM-based.
2. Layers `substations`, `transformers`, `feeders` (straight lines, labelled schematic) in GPKG; graph builder adds them.
3. Flood engine: transformer in catchment with ponding ≥ plinth → **protective shutdown** → downstream `SUPPLIES` → buildings/facilities "power loss"; facilities' backup power = `unknown` (show it). Add to summary + Why? chain.
4. Development: electrical check = transformer headroom after added kVA; upgrade "new transformer" works.
5. UI: electrical layer (loading % colours, dashed, banner "SIMULATED NETWORK — not the actual utility grid"); inspector shows rating/load/plinth and supplied count.

## Out of scope
Load flow, real feeder routes, outage history.

## Acceptance (showcase)
`extreme` preset → Why? chain for a hospital: rain → drain overload → ponding → transformer shutdown → hospital power loss (backup unknown). Development electrical check now pass/conditional/fail with numbers.

## Tests
Every building supplied by exactly one transformer; loading maths; cascade includes the electrical hop only when depth ≥ plinth; baseline untouched.
