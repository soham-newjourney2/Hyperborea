# P03 — 3D Geospatial Command Centre
**Day:** Fri 6 → Sat 7 Nov · **Depends on:** P02 · **Refs:** planning §6, §8, D-07, D-15

## Goal
The pilot in 3D: extruded buildings, roads, facilities, layer manager, asset inspector with provenance, legend, 2D toggle. This is the base every later layer plugs into.

## Steps
**Backend**
1. `services/layer_store.py`: load all GPKG layers at startup into memory (GeoDataFrames + pre-serialised GeoJSON). Layer registry with metadata: id, title, group, geometry type, count, data_status mix, source_ids, default visibility.
2. Endpoints: `GET /region` (boundary + centroid + bbox), `GET /layers`, `GET /layers/{id}` (GeoJSON; optional `?in_pilot=true`), `GET /assets/{id}` (props + empty `relationships: []` until P07).

**Frontend**
3. `components/MapView.tsx`: plain CesiumJS Viewer — **no ion**: `baseLayer` = OSM tiles (`OpenStreetMapImageryProvider`), extra imagery toggle = EOX Sentinel-2 cloudless WMTS; `geocoder:false, baseLayerPicker:false, timeline:false, animation:false, homeButton` custom; terrain = ellipsoid; `requestRenderMode:true`. Fly to region bbox on load.
4. Layers via `GeoJsonDataSource`; buildings extruded by `height_m`, colour by use; roads as polylines by class; facilities as billboards/points with icons by type. Load layers lazily on first toggle.
5. Panels (Zustand store): **Layer Manager** (grouped toggles + counts + data-status chips), **Asset Inspector** (click → name, type, attrs with units, provenance block: status badge, source, observed_at, confidence, assumptions), **Legend**, **status bar** (API state, data timestamp, attribution: "© OpenStreetMap contributors", "Sentinel-2 cloudless by EOX").
6. Provenance badge component used everywhere: Observed (blue) · Curated (teal) · Modelled (amber) · Simulated (purple, dashed outline on map) · Unknown (grey).
7. **2D/3D toggle** using `scene.morphTo2D()` / `morphTo3D()`.
8. Style: professional dark command centre, compact panels, restrained warning colours (inspiration: God's Eye View; no copied code/assets).

## Out of scope
Graph, scenarios, weather. Search box (later if time).
