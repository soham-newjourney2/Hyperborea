# P11 — Air quality, water, land cover
**Day:** Tue 10 Nov · **Depends on:** P03, P05 · **Refs:** DATA_SOURCES `om_aq`, `openaq`, `esa_wc`, `s2_l2a`, `syn_water`

## Goal
Environmental layers with honest status: modelled air quality, demo/curated water points, observed land cover + NDVI.

## Steps
1. **Air:** `services/air.py` Open-Meteo Air Quality (CAMS) hourly PM2.5, PM10, NO₂, O₃ for centroid → 24 h means → India NAQI category for PM2.5/PM10 (CPCB breakpoints in `config/naqi.yaml`, cite source). `data_status=modelled`. Optional: OpenAQ v3 nearest stations if `OPENAQ_API_KEY` set → `observed`, show station location + time. Cache + snapshot like P05.
2. **Water:** if Teammate A found published values → `data/curated/water_quality.geojson` (curated, cite each). Else `data/synthetic/water_quality.geojson` (6–10 points, pH/turbidity/TDS with units + sample dates, `simulated`, banner "DEMO DATA"). Points only — **no interpolation**.
3. **Land cover:** `pipelines/landcover.py` ESA WorldCover 2021 via Planetary Computer → clip → class shares for pilot and per catchment → `data/processed/landcover_stats.json` + coloured PNG overlay (bounds in metadata). NDVI: Sentinel-2 L2A dry-season (Dec–Mar) low-cloud median → NDVI PNG overlay + mean per catchment.
4. Optional flag `runoff_c_source=worldcover` re-derives catchment C; default stays `default` so P08 tests hold — record decision if switched.
5. Endpoints: `/environment/air`, `/environment/water`, `/environment/landcover` (stats + overlay URL).
6. UI **Environment** panel: AQ cards + 72 h chart with NAQI band colours and "modelled (CAMS)" badge; water points with popups (parameter, value, unit, date, status); WorldCover + NDVI overlays (Cesium `SingleTileImageryProvider` with bounds) with legends; % green/built-up per catchment in inspector.
7. Attribution strings added to status bar.

## Out of scope
AQ interpolation, LST/heat modelling, groundwater.

## Acceptance (showcase)
Toggle land cover and NDVI overlays on the pilot; AQ panel shows category + source; water points clearly marked demo/curated.

## Tests
NAQI category function; landcover shares sum ≈ 100%; water layer has units + dates for every record; AQ fallback.
