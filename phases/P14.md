# P14 — Infrastructure health, LLM explainer, reports
**Day:** Wed 11 Nov · **Depends on:** P08–P13 · **Refs:** D-11, VISION §11.5

## Goal
A ranked asset-health view, plain-language explanations grounded only in engine output, and a printable report.

## Steps
1. **Infra health** `engine/health.py`: condition index 0–100 for drains, transformers, roads = weighted (simulated age + simulated last-inspection + baseline utilisation under `heavy` + overload frequency across presets + exposure). Formula + weights shown; `simulated` inputs flagged. Endpoint `/infra-health?type=&top=`. UI **Infrastructure Health** panel: top-10 list, click → map + Why.
2. **LLM explainer (local only):**
   - Ollama portable (Windows zip from the official GitHub releases) → `local/tools/ollama`; `OLLAMA_MODELS=local/ollama/models` (env.ps1 handles PATH).
   - Model: small instruct model with an **OSI licence** that fits 6 GB VRAM — shortlist Qwen3-4B (Apache-2.0) or Phi-4-mini (MIT); verify licence on the model page, record in model card. Set `OLLAMA_MODEL`.
   - `engine/explain.py`: input = result JSON only; prompt = "use only these facts, cite asset IDs, state data status, no new numbers". **Grounding check:** every number in output must appear in input, else fall back to template. Template explainer (deterministic) is the default and the hosted mode (`EXPLAINER=template`).
   - `POST /explain {result_id, asset_id?}` → `{text, mode, grounded:true}`. UI toggle Template / Local LLM (LLM greyed out when unavailable).
3. **Report:** frontend `/report/:resultId` print-optimised page: scenario params, map image (Cesium canvas capture; `preserveDrawingBuffer`), summary metrics, affected-asset table, development comparison (if any), provenance + assumptions + limitations, attributions, timestamp. Print CSS → "Save as PDF". JSON/CSV export buttons. Endpoint `/report/{result_id}` supplies data.

## Out of scope
Cloud LLM APIs, RAG over documents, styled PDF engines.

## Acceptance (showcase)
Health panel ranks assets with reasons; LLM explanation for an affected hospital reads naturally and passes grounding (template on hosted URL); report prints to a clean PDF.

## Tests
Grounding check rejects an invented number; template output deterministic; health index within 0–100; report endpoint 200.
