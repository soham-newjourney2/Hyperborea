# P01 — Setup + scaffold
**Day:** Fri 6 Nov · **Depends on:** — · **Refs:** planning §4, §5, §9

## Goal
Running empty shell: FastAPI `/api/health` + React app showing a Hyperborea header and a green "API OK" badge. Everything installed inside the project.

## Steps
1. Verify base tools, record versions in LOG: `git --version`, `python --version` (3.11–3.12 preferred; 3.13 ok if wheels install), `node -v` (≥ 20), `npm -v`, `claude --version`. Check `git config user.name` / `user.email` are set — if not, ask the user (don't invent).
2. Repo: if `D:\hyperborea` isn't a clone yet, clone `https://github.com/soham-newjourney2/hyperborea` and copy the starter-pack files in (don't overwrite repo files without asking). Confirm `.gitignore` is in place before the first commit.
3. `. .\scripts\env.ps1` (creates `local/` subfolders), then `python -m venv .venv`, re-run env.ps1 to activate.
4. Backend: `backend/requirements.txt` — fastapi, uvicorn[standard], pydantic-settings, geopandas, pyogrio, shapely, pyproj, networkx, httpx, scikit-learn, joblib, pyjwt, pyyaml, pytest. `requirements-pipelines.txt` (offline only) — osmnx, rasterio, rioxarray, pystac-client, planetary-computer, matplotlib. Install both into `.venv`.
5. Backend skeleton: `backend/app/main.py` (FastAPI, `/api` router, CORS from `CORS_ORIGINS`), `core/config.py` (pydantic-settings, reads `.env`), `core/paths.py` (repo paths + local cache defaults), `core/provenance.py` (`DataStatus` enum + Pydantic `FeatureProps` per §6), `api/health.py` (status, version, data timestamp or null).
6. Frontend: `npm create vite@latest frontend -- --template react-ts`; install cesium, vite-plugin-cesium, zustand, tailwindcss, @tailwindcss/vite; vitest as dev dep + `"test": "vitest run"` script. Configure Vite plugins. `src/lib/api.ts` (base URL from `VITE_API_URL`), `src/App.tsx` = dark command-centre shell (header "HYPERBOREA", left panel placeholder, map area placeholder, status bar with API badge). Don't add Cesium viewer yet (P03).
7. `scripts/dev.ps1`: starts uvicorn (`backend.app.main:app`, :8000, reload) and `npm run dev` (:5173) in two windows.
8. Copy `.env.example` → `.env` (local only).
9. Context7: `.mcp.json` is in the pack; run `claude mcp list` to confirm `context7` connects (needs restart of Claude Code if added mid-session).
10. `README.md`: 10-line stub (what it is, `scripts/dev.ps1`, link to planning.md). Full README in P15.
