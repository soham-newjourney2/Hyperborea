# P06 — Drainage network
**Day:** Sun 8 Nov · **Depends on:** P02, P03 · **Refs:** planning §6, §7, D-09, D-16, DATA_SOURCES `cop_dem`, `syn_drain`, `cur_outfall`

## Goal
A clearly **simulated** stormwater network for the pilot with capacities, flow directions, outfalls and catchments — ready for the flood engine.

## Steps
1. `pipelines/fetch_dem.py`: Copernicus DEM GLO-30 tile(s) via Planetary Computer STAC → clip to boundary + buffer → `local/rasters/dem.tif` (not committed). Record vertical accuracy caveat (Salt Lake is flat; DEM slopes are unreliable).
2. `pipelines/build_drainage.py`:
   - Drain segments = one per road edge inside the pilot (side drains follow roads in Salt Lake — **assumption, labelled**). Junction/manhole nodes at road nodes.
   - Node elevation sampled from DEM; outfalls = curated points where the network meets OSM waterways/canals (`cur_outfall`); if none inside, nearest boundary nodes toward the nearest canal — ask the user to confirm outfall placement (show a PNG).
   - Direction: each node drains along the shortest elevation-aware path to its nearest outfall → build a **DAG** (`DRAINS_TO`); verify every node reaches an outfall.
   - Size by road class (assumed): primary/secondary 1.2 m, tertiary 0.9 m, residential/service 0.6 m circular-equivalent. `manning_n=0.015`, `slope=max(dem_slope, 0.002)`.
   - `condition_factor` (simulated, seeded RNG): 0.6–1.0 (siltation/blockage).
   - Capacity: Manning full-flow (planning §7) → `capacity_m3s`, `effective_capacity_m3s`.
   - Catchments: Voronoi of segment midpoints clipped to boundary; C = area-weighted (roof 0.90 from buildings, road 0.85 from road buffers, other 0.40) → `catchments` layer with `area_m2`, `runoff_c`.
   - All drains/manholes/catchments: `data_status=simulated`, `source_id=syn_drain`, `assumptions` text naming each rule.
3. Write layers `drains`, `drain_nodes`, `outfalls`, `catchments` to the GPKG; register in LayerStore.
4. If Teammate A delivered real drainage info (pumping stations, canals, named drains), add as `curated` and note which simulated parts it replaces.
5. UI: drains coloured by effective capacity, width by size, dashed (simulated); outfalls icon; catchments translucent toggle. Inspector shows capacity with the formula and inputs. Banner on layer: "SIMULATED NETWORK — not municipal records".

## Out of scope
SWMM, real survey data, pumps operations.

## Acceptance (showcase)
Toggle Drainage → network on roads with flow arrows/colours; click a drain → diameter, slope, n, condition, capacity (m³/s) + formula + "simulated" badge; catchments visible.

## Tests
DAG (no cycles); every node reaches an outfall; Manning unit test against a hand-computed case; no drain has `data_status` other than simulated/curated; catchment areas sum ≈ boundary area (±2%).
