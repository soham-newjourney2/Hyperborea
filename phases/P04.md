# P04 — Public URL (Vercel + Hugging Face Space) + offline snapshots
**Day:** Sat 7 Nov · **Depends on:** P03 · **Refs:** D-03, D-10, planning §8

## Goal
A public prototype URL judges can open, plus a demo that survives API/network failure. **Deploying requires the user's explicit go-ahead in-session** (accounts + tokens are the user's).

## Steps
1. Ask the user for: Hugging Face username + write token, Vercel login done (`npx vercel login` run by the user). Store `HF_TOKEN`, `HF_SPACE` in `.env` only.
2. `backend/Dockerfile`: python 3.11/3.12 slim, `pip install -r requirements.txt` (no pipelines/ML deps), copy `backend/` + `data/processed|curated|synthetic|snapshots` + `config/`, run uvicorn on **port 7860**, non-root user (HF requirement).
3. `scripts/build_space.ps1`: assemble `deploy/hf-space/` (Dockerfile, backend, data, `README.md` with HF front-matter `sdk: docker`, `app_port: 7860`, title, licence).
4. `scripts/deploy.ps1 -Target api|web|all`:
   - api: create the Space once (docker SDK) and upload `deploy/hf-space` with the `hf` CLI / `huggingface_hub.upload_folder` (check current CLI syntax via Context7/`hf --help`). Set Space secrets (`CORS_ORIGINS`, later `ADMIN_PASSWORD`, `JWT_SECRET`) via the HF UI or API.
   - web: `npm run build` with `VITE_API_URL=https://<space>.hf.space/api`, then `vercel build` + `vercel deploy --prebuilt --prod` from `frontend/` (no Git integration). `vercel.json` SPA rewrite.
   These commands are `ask` in settings — the user approves each.
5. CORS: allow the Vercel domain(s) + localhost.
6. **Snapshots:** `scripts/make_snapshots.py` calls the local API and writes `frontend/public/snapshots/<endpoint>.json` (region, layers list, each layer). `api.ts`: on fetch failure/timeout (5 s) → load snapshot, show **Offline snapshot** badge. Regenerate snapshots at the end of every later phase.
7. Add `docs/DEPLOY.md` (10 lines): URLs, how to redeploy, "wake the Space before demo".

## Out of scope
Custom domain, CI/CD, GitHub-linked deploys.

## Acceptance (showcase)
- Public Vercel URL opens the Command Centre on a phone, data served from the HF Space.
- Stop the API locally / block the Space → app still loads from snapshots with the badge.

## Tests
pytest unchanged and passing. Manual: both URLs + offline fallback, noted in LOG.
