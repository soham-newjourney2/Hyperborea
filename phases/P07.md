# P07 — Relationship engine + explorer
**Day:** Sun 8 Nov · **Depends on:** P06 · **Refs:** planning §6 edge types, §8

## Goal
The central differentiator: one typed, explainable dependency graph across asset types, visible in the UI.

## Steps
1. `backend/engine/graph.py` — `build_graph(store) -> nx.MultiDiGraph`, built at startup:
   - Nodes = all assets (buildings, roads, drains, drain nodes, outfalls, catchments, facilities); node attrs: `asset_type`, `data_status`, key attrs.
   - Edges (each with `relationship_id, type, rule, weight, unit, data_status, confidence, assumptions`):
     `DRAINS_TO` (from P06 DAG) · `ADJACENT_TO` drain↔road (same road edge) · `ACCESSIBLE_VIA` building/facility → nearest road ≤ 50 m (rule text includes distance) · `LOCATED_WITHIN` building/drain → catchment (spatial join) · `DEPENDS_ON` facility → its access roads.
   - Registry of edge-type semantics in `engine/relationships.py` (one place; UI reads it).
2. Helpers: `neighbors(id, depth, types=None)`, `upstream(drain_id)`, `downstream(drain_id)`, `path(src, dst)`, `summary()`.
3. Endpoints: `/graph/summary`, `/graph/neighbors/{id}?depth=1..3&types=`, `/graph/path`, and fill `relationships` in `/assets/{id}`.
4. Frontend **Relationship Explorer** panel: Cytoscape.js (cose/breadthfirst layout) of the selected asset's k-hop neighbourhood, nodes coloured by asset type, edges labelled by type, simulated edges dashed; legend of edge semantics. Click node → select on map + fly. Map highlights the neighbourhood.
5. Inspector "Relationships" tab: grouped list (type → assets) with the rule text.

## Out of scope
GNNs, graph DB, temporal edges (post-qualification).

## Acceptance (showcase)
Click a hospital → explorer shows the roads it depends on → drains along them → upstream drains/catchments; summary shows ≥ 4 node types and ≥ 5 edge types; every edge has a rule.

## Tests
Graph has ≥ 3 node types; every edge type in registry; no edge missing `rule`; isolated/disconnected asset gets no physical edge (VISION §19.3); `upstream` ⊆ ancestors on DAG.
